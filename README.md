# 🧠 GEN-AI & Machine Learning Projects

Welcome to my repository showcasing a collection of my projects in Artificial Intelligence, Generative AI, and Machine Learning. This space tracks my learning journey, ranging from classic tabular data predictions to advanced computer vision and Retrieval-Augmented Generation (RAG).

---

## 📂 Repository Directory

### 🔍 1. Retrieval-Augmented Generation (RAG)
* **Folder:** `RAG`
* **Description:** Implementation of a RAG pipeline to query custom data using Large Language Models (LLMs) and vector embeddings.

### 🖼️ 2. Image Classification Suite
* **Folder:** `Image classification`
* **Description:** Computer vision models trained on standard benchmark datasets (such as MNIST, CIFAR, and Fashion-MNIST) exploring deep learning architectures and CNNs.

### 📈 3. Flight Price Prediction
* **Folder:** `flight_price_prediction`
* **Description:** An end-to-end regression project utilizing machine learning models (like Random Forests) to accurately predict flight fares based on historical travel features.

### 🏥 4. Disease Prediction
* **Folder:** `Disease prediction`
* **Description:** Predictive analysis using healthcare data to classify and detect medical conditions based on clinical symptoms and features.

### 💰 5. Medical Cost Estimation
* **Folder:** `medical cost`
* **Description:** Predictive modeling focusing on regression analysis to estimate healthcare and health insurance costs based on patient demographics.
